    Sincronizar con GitHub

    Tus datos se guardan como un archivo JSON en un repositorio. Usa uno privado.

    Crea un token de grano fino en github.com/settings/personal-access-tokens: acceso solo a ese repositorio y permiso “Contents: Read and write”. Se guarda únicamente en este navegador, nunca en el archivo ni en las copias exportadas.

    En Google Cloud: activa “Google Calendar API”, crea un ID de cliente OAuth tipo “Aplicación web” y agrega la dirección donde abres el tablero (https o http://localhost) como origen autorizado de JavaScript. No funciona abriendo el archivo con doble clic.
